# 되돌리기(롤백) 절차 (2026-10-26 작성)
원칙: 먼저 **추가 입력 중단 공지** → 무엇을 되돌릴지 정함 → 아래 해당 절차 → 되돌린 뒤 **확인 항목**까지 마쳐야 끝.
이 문서는 `HANDOVER_AND_RECOVERY.md`(사고 첫 대응)와 `DATA_FIX_PROCEDURE.md`(데이터 수정)의 보충입니다.

## 1. 코드(화면·계산)를 되돌릴 때
| 순서 | 할 일 | 확인 |
|---|---|---|
| 1 | GitHub Actions에서 마지막 정상 배포 커밋을 찾는다(Run Tests·Deploy·Post-deploy verify가 모두 success인 가장 최근 커밋) | 커밋 번호 메모 |
| 2 | 문제 커밋을 `git revert <커밋>` 후 push(기록이 남는 방식. `reset --force`는 쓰지 않는다) | CI 3단계가 다시 success |
| 3 | 급하면 Vercel에서 이전 배포를 운영으로 되돌릴 수 있으나, 이후 다음 push가 최신 main을 다시 올리므로 **반드시 2번도 함께** 한다 | 운영 화면 새로고침(Ctrl+F5) 후 버전 확인 |
| 4 | 파일을 고쳤다면 `?v=` 버전(캐시버스팅)도 함께 올라갔는지 확인 | 옛 화면 안내 배너가 안 뜸 |

## 2. DB 규칙(SQL)을 되돌릴 때
각 적용에는 짝이 되는 되돌리기 파일이 `docs/db/`에 있습니다. **적용 SQL과 항상 한 쌍으로 보관**합니다.
| 적용한 것 | 되돌리기 파일 |
|---|---|
| 단계 규칙(shadow) | `2026-10-26_stage_rule_rollback.sql` |
| 보안 묶음 | `2026-10-26_security_batch_rollback.sql` |
| 실장 권한 자동시험 확장(25항목) | `2026-10-26_selftest_extend_rollback.sql` |
순서: ① 되돌릴 SQL 내용을 선혜님과 함께 읽기 → ② 선혜님 승인 → ③ 실행 → ④ 읽기 전용 확인(아래 5번) → ⑤ 기록(마스터 문서). 승인 없이 운영 DB를 바꾸지 않는다.
주의: 되돌리기 SQL은 **새로 만든 함수·트리거만** 없애며, 그 사이에 저장된 고객·견적서 데이터는 지우지 않는다(데이터는 3번으로 복구).

## 3. 데이터(고객·견적서·입금)를 되돌릴 때
1. 변경 이력 표(`customer_history`, `estimate_history`)에서 바뀌기 전 값을 확인한다.
2. 이력에 없으면 구글 드라이브 `DAH_자동백업`의 가장 가까운 날짜 `DAH_백업_YYYY-MM-DD.json`에서 해당 행만 찾는다(파일이 약 10MB라 이 작업 환경에서는 내려받지 못하므로 선혜님이 내려받아 첨부).
3. `DATA_FIX_PROCEDURE.md` 절차로 한 행씩 복구(수정 전 값 기록 → 수정 → 재검산). 돈이 걸린 행은 선혜님 사실 확인 후에만.
4. 복구 후 `data_integrity_issues`와 월 매출을 대조.
※ 전체 시점 복구(PITR)는 현재 요금제에서 가능한지 **확인되지 않음**(R-14, H-6 확인 대상).

## 4. 구글 스크립트를 되돌릴 때
1. 붙여넣기 **전에** 기존 코드를 통째로 복사해 `기존코드_백업_날짜` 파일로 저장해 둔다(오늘 10-26 이 방식으로 보관).
2. 문제가 생기면 그 파일 내용을 전체 선택해 되돌려 붙이고 저장.
3. 붙인 뒤 53번째 줄 `DAH_SCRIPT_VERSION`이 의도한 버전인지 캡처로 확인. 매일 메일 본문의 버전으로도 확인.
4. 파일을 다른 곳에 넘길 때는 **[파일 + 해시 + 확인할 줄 번호]를 한 묶음**으로 준다(F-11 규칙).

## 5. 되돌린 뒤 확인 항목(모두 해야 "끝")
- [ ] CI 3단계(Run Tests → Deploy → Post-deploy verify) success
- [ ] `staff_permission_selftest()` 전 항목 ok (실장 권한이 열려 있지 않음)
- [ ] `data_integrity_issues` 새 경고 없음(기존 알려진 건 제외)
- [ ] 월 매출·고객 합계가 되돌리기 전과 같거나 의도한 값
- [ ] 선혜님 화면(Ctrl+F5)에서 핵심 동작 1~2개 직접 확인
