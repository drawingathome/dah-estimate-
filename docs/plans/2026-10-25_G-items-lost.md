# G 항목 분실 기록 (2026-10-25)

## 무엇이 없어졌나
v5 4단계의 "기존 18건" 중 G1, G3~G6, G8, G9, G11, G12, G14, G15 (12개)의 **내용**. 번호만 남았다.

## 확인된 것
- G7 = 견적서 앱 보관(archived) 견적 입력 가드, G13 = 설문앱 retryPendingSurveys 중복 방지 (1-11에서 처리).
- 정의는 v5(10-14 18:30)보다 앞선 10-12~10-14 오전 대화의 알파벳 점검표에 있었던 것으로 보임. 서버 로그·저장소·프로젝트 문서·메모리 어디에도 원문 없음.
- G7·G13이 모두 견적서 앱·설문앱 쪽 항목이므로 G는 "다른 앱의 쌍둥이 버그·가드" 묶음일 가능성이 높음(추정).

## 원인
계획서를 같은 문서에 덮어쓰며 갱신했고, 알파벳 점검표는 대화창에만 있었으며, 항목을 번호만으로 인용했다.

## 대체 방침
- 원문 복원을 접고, 현재 코드·DB를 기준으로 쌍둥이 전수표를 새로 만든다 (`docs/audit/`).
- 새 항목은 T-번호 + 내용 + 근거 + 완료 기준으로 적는다.
